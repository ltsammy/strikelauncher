# Strike Launcher

Offizieller Launcher für **Age of Clones – Strike Platoon (104th Battalion)**.

Der Launcher übernimmt für dich:

- Prüft, ob alle benötigten Arma 3 Mods installiert sind, und abonniert/lädt fehlende automatisch über den Steam Workshop nach
- Startet TeamSpeak 3 (mit Task Force Radio Plugin) und verbindet dich automatisch mit unserem Server
- Startet Arma 3 direkt mit optimierten Einstellungen und verbindet dich mit dem Server
- Aktualisiert sich von selbst

## Download

Neueste Version: **[github.com/ltsammy/strikelauncher/releases/latest](https://github.com/ltsammy/strikelauncher/releases/latest)**

Dort `StrikeLauncher-win-Setup.exe` herunterladen und ausführen. Das war's – die
restlichen Dateien auf der Release-Seite brauchst du nicht.

## Benutzung

1. Launcher öffnen
2. Auf **START** klicken
   - Fehlende Mods werden automatisch abonniert und heruntergeladen (Steam muss dafür laufen)
   - TeamSpeak 3 öffnet sich und verbindet automatisch mit unserem Server
   - Arma 3 startet und verbindet automatisch mit dem Server
3. Fertig – viel Spaß!

Solange Arma 3 läuft, zeigt der Button "LÄUFT" an. Wenn du Arma 3 beendest, schließt
sich TeamSpeak automatisch mit.

Oben links siehst du deinen eingeloggten Steam-Account sowie den Online-Status von
Arma- und TeamSpeak-Server.

## Einstellungen

Über das Zahnrad-Symbol oben rechts erreichst du die Einstellungen, falls Arma 3 oder
TeamSpeak 3 z. B. nicht automatisch gefunden wurden – dort lässt sich der jeweilige
Installationspfad manuell setzen.

## Voraussetzungen

- Windows 10/11 (64-bit)
- [Steam](https://store.steampowered.com/) mit Arma 3, installiert und eingeloggt
- [TeamSpeak 3 Client](https://www.teamspeak.com/en/downloads/) (wird bei Bedarf zum Download angeboten, falls nicht vorhanden)

## Probleme?

Wende dich an die Team-/Serverleitung von Age of Clones – Strike Platoon.
